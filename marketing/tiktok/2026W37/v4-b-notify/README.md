# V4-B: 通知を3日無視したら、家まで来た。

AI生成の成人女性キーフレームを使い、Fitletの実スクワット画面を3.2秒付近に差し込んだ10秒プロトタイプ。

- フック：玄関を開けた瞬間の異様な近距離＋「3回、無視したよね？」
- Fitletの役割：取り立て屋が命じるスクワットの正体、`3/10` の証拠
- オチ：美女が「明日は、逃げないでね。」と言ってドアを閉める
- 音声：Irodori用台本は `irodori-script.md`。現動画は字幕＋効果音で初速判定用。
- 注意：AI生成画像はキーフレーム。最終版では人物の歩行、指差し、家具移動、ドア閉鎖をAI動画で置換する。
