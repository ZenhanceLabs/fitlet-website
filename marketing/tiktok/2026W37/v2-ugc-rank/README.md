# V2 / UGC curiosity: 「これ何の順位？」

## 採用理由

Chat側のクリエイティブディレクションを反映した、9.2秒の短尺プロトタイプ。
冒頭はFitletを説明せず、意味不明な「9位」から開始する。後半で実アプリ画面を証拠として連続提示し、最後に冒頭へ戻る。

## 使用素材

- `assets/png/onboarding/3.png`: リーグ画面。「ブロンズIII」「9位」を違和感の証拠にする
- `assets/png/onboarding/2.png`: ワークアウト画面。実写＋姿勢推定＋`3/10`を機能の証拠にする
- `assets/png/onboarding/1.png`: ホーム画面。`Lv.4`、ストリーク、FP、トレーニング開始を世界の全体像として見せる
- 音は既存の短い通知音とランクアップ音のみ。音声は別途Irodoriで差し替える前提

## 判断

これは完成広告ではなく、実素材だけで「広告臭を消した場合の骨格」を確認する試作。人物フック、手持ちの実写、Irodori音声を加える版は、この試作の視聴維持を確認してから派生させる。
