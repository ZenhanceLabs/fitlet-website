# Fitlet TikTok カルーセル試作 / 2026W37

## 目的

Fitletの機能説明から始めず、カード単体の謎・違和感・ユーモア・物語でスワイプを止めるための初回クリエイティブ試作です。TikTokアカウント作成、ログイン、投稿、API取得は行っていません。

主KPIは再生数です。カルーセルとして検証する場合は、次に「1枚目から2枚目への遷移率」「最終カード到達率」「保存率」「シェア率」「プロフィール遷移」を見ます。Fitletのインストールは、勝ち筋が見えた後の二次KPIとして追加します。

## 生成物

すべて縦長 1080x1920 PNGです。ファイル名は `CF / HK / AN / V` の実験IDを含みます。

なお、同じ出力ディレクトリには別プロセスで先に生成されていた `ai-oddity/` の4枚（`card-01`〜`card-04`）もあります。既存成果物として保持し、今回の `cards/` セットとは上書き・混在させていません。今回追加したカードだけが、下記の実験ID命名規則と4 Family構成の対象です。

### CF01 / 記憶されるサボり

- `cards/CF01-HK05-AN01-V01.png` — 「運動してない日、ウミウシだけは覚えてる。」
- `cards/CF01-HK05-AN01-V02.png` — 「私は忘れた。あの子は、見ていた。」
- `cards/CF01-HK05-AN01-V03.png` — 「だから今日は、1分だけ裏切れない。」 / 小さく Fitlet

意図は、サボりを笑わず、記録する視線だけをキャラクターに移すことです。V01で共感、V02で謎、V03で小さな行動に着地します。

### CF02 / 反転するランキング

- `cards/CF02-HK04-AN02-V01.png` — 「最下位が、今日いちばんえらい。」
- `cards/CF02-HK04-AN02-V02.png` — 「8位に落ちた。——ちがう。8位まで戻った。」
- `cards/CF02-HK04-AN02-V03.png` — 「勝つことより、戻ることを記録する。」 / 小さく Fitlet

実在ユーザーや実績のランキングではなく、物語上の「架空のランキング」と明記しています。勝敗を煽るより、復帰という意味反転を主役にします。

### CF03 / 通知という敵キャラ

- `cards/CF03-HK07-AN03-V01.png` — 「今日の敵、腹筋じゃない。通知。」
- `cards/CF03-HK07-AN03-V02.png` — 「通知は、やる気を一枚ずつ盗む。」
- `cards/CF03-HK07-AN03-V03.png` — 「敵を消す前に、1クエストだけ残した。」 / 小さく Fitlet

機能説明ではなく、通知・眠気・残業を画面上の敵として扱います。V03はAI生成の海底背景と既存ウミウシを混ぜ、カードだけでも世界が一段変わるようにしました。

### CF04 / 高分散：時計に追われる架空の成人アスリート

- `cards/CF04-HK01-AN04-V01.png` — 「この人、時計に追われてる。」 / 「0.5秒で、意味が変わる。」
- `cards/CF04-HK01-AN04-V02.png` — 「次に走り出すのは、私か、時計か。」 / 「答えは、まだ出さない。」 / 小さく Fitlet

視聴回数の最大化を目的に、キャラクター性・ファッション誌的な強い画面・巨大な小道具を導入した高分散Familyです。実在人物を参照していない架空の成人キャラクターで、非性的・スポーツ表現に限定しています。AI生成素材を含むため、動画化して公開する場合はTikTok側のAI表示要否を確認します。

## Irodori向け音声台本

音声はカードを動画化する場合の仮台本です。カード自体には音声を埋め込んでいません。秒数は1枚目→2枚目→最終カードの切り替えを想定した12〜16秒版です。読み上げは短く、余白と効果音で視聴維持を作ります。

### CF01 / 記憶されるサボり

- 0.00–0.50秒：無音。紙をめくる音を極小で1回。最初のカードを即表示。
- 0.50–2.00秒：「運動してない日。」低めの小声、言い切って0.25秒止める。
- 2.00–4.20秒：「ウミウシだけは、覚えてる。」少し近いマイク感。最後の「覚えてる」を残す。
- 4.20–6.60秒：小さな虫眼鏡の金属音。声は入れず、2枚目へ。
- 6.60–9.20秒：「私は忘れた。あの子は、見ていた。」淡々と、責めない。
- 9.20–12.60秒：「だから今日は、1分だけ。」最後の「だけ」を小さくする。
- 12.60–14.00秒：水中の泡音。最終カードの「つづきは、まだ途中。」で止め、カード1へループ。

### CF02 / 反転するランキング

- 0.00–0.50秒：低いキック音1発と同時に「最下位。」を表示。
- 0.50–2.00秒：無音の間。アナウンサー声を使わず、順位カードを見せる。
- 2.00–4.00秒：「でも、今日いちばんえらい。」少しだけ明るく、語尾を上げない。
- 4.00–6.00秒：順位札が落ちる紙音。2枚目へ。
- 6.00–9.00秒：「8位に落ちた。——ちがう。」一度言い切り、0.3秒の間。
- 9.00–11.50秒：「8位まで戻った。」ここだけ音程を一段上げる。
- 11.50–14.50秒：「勝つことより、戻ることを記録する。」落ち着いた声、最後に小さなページをめくる音。
- 14.50–16.00秒：次の順位が見えそうで見えない電子音。最初の「最下位。」へ戻せるように終える。

### CF03 / 通知という敵キャラ

- 0.00–0.50秒：通知音を3連打。1音目は左、2音目は右、3音目は中央。
- 0.50–1.80秒：「今日の敵、腹筋じゃない。」早口ではなく、敵を紹介する実況調。
- 1.80–2.60秒：0.2秒の無音。「通知。」だけ低く、乾いた声。
- 2.60–5.00秒：通知バッジのポップ音を不規則に4回。カード2へ。
- 5.00–8.00秒：「通知は、やる気を一枚ずつ盗む。」半分ナレーション、半分告発。
- 8.00–10.60秒：眠気のあくび、残業のキーボード音、最後に短いホイッスル。
- 10.60–13.60秒：「敵を消す前に、1クエストだけ残した。」最後の「残した」をささやく。
- 13.60–15.00秒：海中の低いブーン音。答えを説明せず、次の通知音の直前でループ。

### CF04 / 時計に追われる架空の成人アスリート

- 0.00–0.50秒：目覚ましベルを1回だけ大きく鳴らし、人物と巨大時計を一瞬で表示。
- 0.50–2.20秒：「この人、時計に追われてる。」ファッション誌の予告編のように、明るく断定。
- 2.20–3.00秒：時計の秒針だけ。声を切る。
- 3.00–5.50秒：「……と思った？」少し笑いを含ませ、カード2へ。
- 5.50–8.80秒：「次に走り出すのは、私か、時計か。」疾走感は出すが、煽らない。
- 8.80–11.40秒：足音を2歩、時計のベルを遠くで1回。黄色い未完了ボックスを残す。
- 11.40–14.00秒：「答えは、まだ出さない。」低く、余韻を残して終える。
- 14.00–15.00秒：秒針が一周する音。カード1のベルへ戻る。

## 検証方法

レンダーは `scripts/render_cards.swift` で行いました。macOS標準の Swift / AppKit / CoreGraphics でローカル合成し、既存素材のPNGとAI生成の補助素材を読み込んでPNG化しています。依存追加、アプリコード変更、設定変更はありません。

確認済みの項目：

- `sips -g pixelWidth -g pixelHeight cards/*.png` で全11枚が `1080 x 1920`
- 全11枚をコンタクトシート化して目視確認
- 日本語の主文、Familyコード、最終カードの小さなFitlet表記を確認
- CF04は「架空の成人キャラクター」「FICTIONAL / AI VISUAL」をカード上にも表示
- 既存アプリ側の未コミット差分は変更していない
