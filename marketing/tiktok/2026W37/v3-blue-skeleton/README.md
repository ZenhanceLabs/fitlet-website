# V3 / 高モデル採用案: 「青い人、ずっとついてくる」

高モデルのChatで再評価した結果の第一候補。広告のフックを外部の美女やAI映像に借りず、Fitlet固有の水色スケルトンを最初は心霊・異常現象として見せる。

## 構造

1. 0.0–4.7秒: UIを切った水色スケルトンの超寄り。人間についてくる異常として扱う
2. 4.7–5.0秒: 無音の溜め
3. 5.0–6.4秒: 実ワークアウト画面、`3/10`まで一気に開示
4. 6.4–7.3秒: リーグ画面、ブロンズIII・9位
5. 7.3–8.5秒: ホーム画面、Lv.4・ストリーク7・FP168
6. 8.5–10.0秒: ワークアウトへ戻り「残り7回」→最初の骨格クロップへループ

## 使用素材

- `assets/png/onboarding/2.png`: 骨格の異常→ワークアウトの証拠
- `assets/png/onboarding/3.png`: 順位システムの証拠
- `assets/png/onboarding/1.png`: 継続・ゲーム世界の証拠
- 既存の短い通知音とランクアップ音。ナレーションはIrodori差し替え前提

## セリフ案

- 「これ、私にしか見えない？」
- 「え、動いた」
- 「ずっとついてくるんだけど」
- 「フィットネスかよ」
- 「しかもランク戦ある」
- 「気づいたら7日やってた」

## 不使用

ストア用人物素材、AI美女、AI生成人物、意味のない海牛単体、ロゴだけの画、機能一覧、企業コピー、App Store風レイアウト。

## 制限

これは実アプリ画面から作った構造検証用プロトタイプ。人物の手持ち撮影とIrodori音声を足す前に、骨格クロップだけで視聴が止まるかを確認する。
