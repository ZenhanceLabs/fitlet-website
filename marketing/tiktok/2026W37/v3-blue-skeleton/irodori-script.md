# Irodori voice script / V3

## Direction

広告ナレーションではなく、スマホを見ながら独り言を言っている声。最初は小声、4.7秒の無音を残し、5秒以降だけ少し素に戻す。過剰な演技・煽り・企業っぽい抑揚は使わない。

## Lines

| Time | Voice |
|---|---|
| 0.25–0.80 | これ、私にしか見えない？ |
| 0.80–1.50 | え、動いた |
| 1.50–3.00 | （低い環境音だけ。台詞なし） |
| 3.00–4.70 | ずっとついてくるんだけど |
| 4.70–5.00 | 無音 |
| 5.00–6.40 | フィットネスかよ |
| 6.40–7.30 | しかもランク戦ある |
| 7.30–8.50 | 気づいたら7日やってた |
| 8.50–9.50 | 残り7回。 |

## Audio mix

声は近接マイク風、軽い部屋鳴り。通知音は0.4秒、ランクアップ音は5.2秒に薄く置く。BGMは初回テストでは入れず、声と画面変化だけで維持できるかを測る。
